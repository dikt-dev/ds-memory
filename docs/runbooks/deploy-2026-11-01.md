## 4. 回滚

发布前记下的 version id，直接回退：

```powershell
npx wrangler rollback <version-id> -c wrangler.local.toml
```

**什么时候回滚**（任一命中就退，别现场调试）：

- `/health` 不通，或 5 分钟内恢复不了；
- 回复明显失忆、串台、编造事实；
- 归档链路报错且当天修不好；
- `recall-samples` 显示 `timedOutRate` 显著上升（>10%）。

回滚**不影响数据**：R2 的 memory.md、D1 的表都没被迁移，新版只是多读多写。
