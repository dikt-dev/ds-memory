## 现在就能做（10/28–11/01，观察期内）

### P-01 自动回归每日执行

**开始：现在**

把 `scripts/memory-regression.mjs` 接到每日归档后或独立 cron：

- 只读 `/api/admin/memory/recall`；
- 结果写 `engine_metrics` 或单独表；
- 失败只告警，不影响线上。

验收：

```text

失败可定位到 case id
```

### P-02 扩充回归样本与基线

**开始：现在**

当前只有 4 条样本，至少补到 20 条：

- 同事件；
- 同实体；
- 无关；
- 冲突/更正；
- 时间标签/`[END]` 污染。

记录基线：

```text
命中率、噪声率、linked_items、注入字符、首字延迟
```

### P-03 分层子预算细化

**开始：现在**

参照 Companion 的“子预算不可互借”：

```text

近期摘要

```

每类独立上限，未用完不借给其他层。

验收：

```text
任一子预算膨胀不会挤掉固定记忆
manifest 能看出哪一层被裁
```

### P-08 跨日期近重复事实合并

**开始：11/01–11/07**

需要 P-02 的样本和基线，避免误合并：

```text
“我喜欢猫”
“我喜欢猫但不想养”
```

方案：

- 语义相似候选；
- 同 section/subject/predicate；
- 先入待审，不直接删；
- 保留来源和 `valid_to`。
