# 网页端界面 · 纸墨（Paper & Ink）

> 2026-10-31 重做。旧版是蓝色玻璃拟态：径向渐变背景、半透明毛玻璃、渐变按钮、投影气泡。
> 它的问题是「抢戏」——一屏对话里颜色、模糊、阴影都在动，字反而不突出。

## 1. 为什么选这套

| 候选 | 为什么没选 |
|---|---|
| 继续玻璃拟态 / 渐变蓝 | 和手机端割裂；长对话下背景色会透进气泡，字发灰 |
| 深色仪表盘风 | 这是聊天，不是控制台；一屏只有两个人说话 |
| 极简黑白（Swiss） | 干净但太冷，和「小忆」这个角色不搭 |
| **纸墨（暖纸 + 单一靛紫）** | 手机端 DS-Mobile 已经是这套；网页只用把纸铺宽，两端切换不用重新认界面 |

核心三条和手机端一致：

1. **底色是纸**（暖白 `#F7F6F3`），正文近黑 `#17171A`，对比 15:1；
2. **全局只有一个彩色**（靛紫 `#4B3FD1`），它只出现在「我」的气泡、主按钮、链接上；
3. **不用投影分层**，用 1px 发丝线和留白分层；毛玻璃、渐变、彩色描边全部去掉。

## 3. 版面

- **一列到底**：内容列宽 `--col: 820px`，顶栏、消息区、输入区共用同一条中线；
- **气泡**：她的白底 + 发丝线，我的靛紫实底；只有每组第一条带 6px 小角，其余全圆角；
- **分组**：同一个人连着说话时气泡贴紧（4px），头像只在第一条出现；换人留 16px；
- **元信息不上版面**：每条消息的费用、复制按钮默认透明，鼠标悬停才浮出来，长对话不被小字打断；
- **顶栏**：左侧头像 + 名字 + 在线；中间是日期 / 今日费用 / 余额，用 `·` 分隔而不是一排胶囊；
- **图标**：全部内联 SVG（线性 1.7px），不再用 emoji 当结构图标；
- **输入区**：图片/文件是两个 42px 圆形浅底按钮，输入框是无边框的浅底胶囊，发送是 42px 圆形实心；
- **宽屏**：820px 阅读列，两侧留白；**窄屏（≤680px）**：顶栏折行、元信息单独一行可横滑、气泡放宽到 82%。
