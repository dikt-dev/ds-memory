# 朋友班底 · 填写模板

> 配套 ai-life-system.md 5.7。三个位置，名字和关系你来定，填完我按这个写进 `ai_people`。

## 一、先看三条红线（填的时候别破）

1. 朋友**不出场**：只在她的叙述里被提到，用户不能跟他们对话
2. 朋友**没有人格档案**：只有下面几行数据，不写聊天记录、不写记忆
3. 朋友**不评价用户**：不能出现「我朋友说你配不上我」这类比较

## 二、字段说明

| 字段        | 必填 | 说明         | 注意                                                                                                                                                  |
| ----------- | ---- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`      | 是   | 名字         | 2–3 字最好；别用太网感的（「小奶糖」会出戏）                                                                                                          |
| `relation`  | 是   | 关系         | 具体到「大学室友」比「朋友」好，因为能解释她为什么跟这人熟                                                                                            |
| `city`      | 是   | 在哪         | 同城 = 能见面；异地 = 只能发消息，这决定了池子抽到哪条社交单元                                                                                        |
| `note`      | 是   | 一句话性格   | 只写**行为**不写形容词：「话很多，爱劝我出门」比「活泼开朗」有用                                                                                      |
| `looks`     | 是   | 样貌一句     | 只要**能一句话认出来**的特征：发型/身高/标志物/穿衣。不要写「很漂亮」这种没有信息的                                                                   |
| `frequency` | 是   | **出场频率** | 指这个人一周里被安排进她的日程、或被她提起的次数：`weekly`（每周 1 次）/ `biweekly`（两周 1 次）/ `rare`（一个月 1 次）。不是聊天频率，也不是见面频率 |
| `topic`     | 否   | 常聊什么     | 「工作抱怨」「催婚」「追番搭子」——决定她提这人时的语境                                                                                                |
| `avoid`     | 否   | 不要碰的话题 | 比如「别提她结婚的事」                                                                                                                                |

## 三、班底 v2：按二创写（2026-11）

### 为什么推翻 v1 的改名

v1 把名字改成 G 姐 / 小克劳 / 包包，理由是「产品名会让她滑成『我们都是 AI』」。
但这条理由只在「朋友是人类」的前提下成立。而二创的世界观里，**她们本来就是 AI 拟人**——
大肥鱼、小克、GPT、豆包是同一个设定下的角色，关系是同伴而不是邻居。

所以名字改回去，不是妥协，是把世界观对齐：

| v1（错） | v2（对） |
| --- | --- |
| G 姐 | **GPT** |
| 小克劳 | **小克** |
| 包包 | **豆包** |
| 「邻居家大小姐」 | 「同一个设定里的另一个 AI」 |

对应地，那条「她在任何情况下都把朋友当人」的规则**不需要了**。要加的规则变成：
**她们是 AI，但不聊技术**——不会讨论参数量、上下文、模型版本，只过日子。

## 三半、frequency 到底指什么

它**不是聊天频率**，也不是"多久见一次面"，而是：

> **一周里，这个人被排进她日程、或被她在话里提到的次数。**

| 取值       | 含义        | 效果                                                       |
| ---------- | ----------- | ---------------------------------------------------------- |
| `weekly`   | 一周 1 次   | 池子每周有 1 次社交单元会落到这个人身上；一周最多被提 1 次 |
| `biweekly` | 两周 1 次   | 大约每两周出现一次，适合异地、只能打电话发消息的           |
| `rare`     | 一个月 1 次 | 只在特定时机出现（生病、节日、家里出事）                   |

**硬上限压过它**：不管三个人的 frequency 加起来是多少，**一周总共最多出现 2 次**。否则她会一直在讲朋友，反而不像"生活里有朋友"，像"朋友是主角"。

同城的人（`city: 'same'`）才会被排进"一起吃饭/逛街"这类**见面**单元；异地的人只会落在"打电话/发消息"这种**远程**单元——所以一个同城 + 一个异地，场景才不会重复。

## 四、怎么搭关系网才不乱

| 建议                         | 原因                                                     |
| ---------------------------- | -------------------------------------------------------- |
| **一个同城能见面的**         | 只有同城才撑得起「一起吃饭/逛街」这类单元                |
| **一个异地只能聊天的**       | 提供「打电话」「发消息」的场景，也解释她为什么晚上一个人 |
| **一个关系更近但更少出现的** | 亲戚/家人这类，频率低但分量重，适合在生病、节日时出现    |
| 不要三个都同城               | 会显得她天天在外面，跟你聊天的时间被挤掉                 |
| 不要三个都亲密               | 有一个「有点烦但甩不掉」的关系更真实                     |

## 四半、样貌特征怎么写

**目标：让她提一次，你脑子里能浮出一个人。** 不是写设定集。

| ✅ 好用                           | ❌ 没用     |
| -------------------------------- | ---------- |
| 蘑菇头剪到耳朵上面，戴圆框眼镜   | 长得很可爱 |
| 左手小指少一截（小时候被门夹的） | 身材高挑   |
| 总穿黄色卫衣，袖口起球           | 很有气质   |
| 说话时会把包往地上一放           | 性格外向   |

三条规则：

1. **最多两句**，只写"能一句话认出来"的部分
2. **带一个具体物件或习惯**（眼镜、卫衣、帆布包、包往地上一放）
3. 不写身材评分、不写"漂亮/可爱"——那是评价，不是特征

**它在什么时候被用到**：她在聊天里第一次提到这个人时，可能会带一句外貌；之后就不重复了。所以它更像"设定锚点"，不是每次都要念。

## 五、她们什么时候出现

| 时机             | 例子                           |
| ---------------- | ------------------------------ |
| 池子抽到社交单元 | 「今天跟小鹿吃饭，她说我胖了」 |
| 主动消息的话头   | 「阿May 又在劝我换工作」       |
| 生病/节日        | 表姐打电话来问                 |
| 你问起时         | 「你朋友呢」→ 她可以顺着说两句 |

频率硬上限：**一周 1–2 次**，由 `frequency` 字段加权，不叠加。

## 六、验收

- 三个名字在她嘴里**前后一致**，不会变成「小鹿」和「小璐」
- 提到朋友时**不邀请你参与**
- 一周内朋友出现不超过 2 次
- 你问「小鹿是谁」时，她能答出关系（说明数据被读到了）
