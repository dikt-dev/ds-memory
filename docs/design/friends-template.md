# 朋友班底 · 填写模板

> 配套 ai-life-system.md 5.7。三个位置，名字和关系你来定，填完我按这个写进 `ai_people`。

## 一、先看三条红线（填的时候别破）

1. 朋友**不出场**：只在她的叙述里被提到，用户不能跟他们对话
2. 朋友**没有人格档案**：只有下面几行数据，不写聊天记录、不写记忆
3. 朋友**不评价用户**：不能出现「我朋友说你配不上我」这类比较

## 二、字段说明

| 字段 | 必填 | 说明 | 注意 |
| --- | --- | --- | --- |
| `name` | 是 | 名字 | 2–3 字最好；别用太网感的（「小奶糖」会出戏） |
| `relation` | 是 | 关系 | 具体到「大学室友」比「朋友」好，因为能解释她为什么跟这人熟 |
| `city` | 是 | 在哪 | 同城 = 能见面；异地 = 只能发消息，这决定了池子抽到哪条社交单元 |
| `note` | 是 | 一句话性格 | 只写**行为**不写形容词：「话很多，爱劝我出门」比「活泼开朗」有用 |
| `frequency` | 是 | 出现频率 | `weekly`（每周 1 次）/ `biweekly`（两周 1 次）/ `rare`（一个月 1 次） |
| `topic` | 否 | 常聊什么 | 「工作抱怨」「催婚」「追番搭子」——决定她提这人时的语境 |
| `avoid` | 否 | 不要碰的话题 | 比如「别提她结婚的事」 |

## 四、怎么搭关系网才不乱

| 建议 | 原因 |
| --- | --- |
| **一个同城能见面的** | 只有同城才撑得起「一起吃饭/逛街」这类单元 |
| **一个异地只能聊天的** | 提供「打电话」「发消息」的场景，也解释她为什么晚上一个人 |
| **一个关系更近但更少出现的** | 亲戚/家人这类，频率低但分量重，适合在生病、节日时出现 |
| 不要三个都同城 | 会显得她天天在外面，跟你聊天的时间被挤掉 |
| 不要三个都亲密 | 有一个「有点烦但甩不掉」的关系更真实 |

## 五、她们什么时候出现

| 时机 | 例子 |
| --- | --- |
| 池子抽到社交单元 | 「今天跟小鹿吃饭，她说我胖了」 |
| 主动消息的话头 | 「阿May 又在劝我换工作」 |
| 生病/节日 | 表姐打电话来问 |
| 你问起时 | 「你朋友呢」→ 她可以顺着说两句 |

频率硬上限：**一周 1–2 次**，由 `frequency` 字段加权，不叠加。

## 六、验收

- 三个名字在她嘴里**前后一致**，不会变成「小鹿」和「小璐」
- 提到朋友时**不邀请你参与**
- 一周内朋友出现不超过 2 次
- 你问「小鹿是谁」时，她能答出关系（说明数据被读到了）
