## 够不够？先算一笔

| 变量 | 估计 |
| --- | --- |
| 有看点番的日子 | 约 22% |
| 同时活跃 | ≤ 3 部 |
| 一部番消耗 | 2–4 周（12 集的番快，87 集的慢） |

=> 40 部 ≈ **1.5–2 年**的观看量，还不算重温。

所以 **40 部够了**。真要更多，靠后面「片单里没合口味 → AniList 搜一部 → 落库」这条补充通道，不用现在堆。

## 挑片原则

- 口味稳定才像人：她偏治愈 + 日常，偶尔热血，虐的只在大情绪后看
- **按心情挑 vibe**：`healing` 心情低、`hype` 精神好、`mystery` 无聊想刺激、`sad` 想哭一场
- 长番（87/64 集）放进来是为了「追了半年」这种真实感

## 数据格式

```ts
interface AnimeEntry {
  title: string;
  total: number;          // 集数；剧场版填 1，另用 duration
  genres: string[];
  vibe: 'healing' | 'daily' | 'hype' | 'mystery' | 'sad';
  reason?: string;        // 她为什么喜欢（可被引用）
}
```

## 两个注意

1. **集数不必精确**，只影响「追平」的时点，差一两集无所谓；但别写成 0
2. **她可以不喜欢某部**：片单是候选池，不是必看清单；抽到不感兴趣的就换一部，连续两次不感兴趣就降低权重
